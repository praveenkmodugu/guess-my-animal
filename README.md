# Guess My Animal – AI-Assisted Python Game

## About
An interactive Python guessing game developed as part of Stanford Code in Place X. The player asks yes/no questions to identify a randomly selected hidden animal. The game uses AI-generated responses to help the player narrow down the answer.

## Features
- Random animal selection.
- Interactive yes/no question-based gameplay.
- AI-generated responses to player questions.
- Python-based game logic.

## Technologies Used
- Python
- AI-assisted response generation

## How It Works
1. The game selects a hidden animal.
2. The player asks questions to identify it.
3. The AI helper generates yes/no responses.
4. The player continues asking questions until they guess the animal correctly.

## Project Context
This project was completed as part of Stanford Code in Place X.

## Running the Project
The program uses the Code in Place environment's `animal` and `ai` helper modules. Those dependencies are not included in this repository, so the program may not run independently outside the course environment.
